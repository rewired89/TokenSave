# CLAUDE.md

## Git workflow (repo-specific rule — do not ask about this again)

Always commit and push directly to `main`. Do not create side branches, do
not open pull requests unless explicitly asked. This applies to every
session working in this repo, regardless of any default branch-per-session
convention a harness might otherwise suggest.

## Repo layout

Two independent packages, one repo — see `README.md` for the full status
table and why they're kept together. Quick orientation:

- `save-tokens/` — draft compressor (`compress.js`), CLI, browser
  extension, AutoHotkey hotkey. `npm test` from inside this directory runs
  the Jest suite.
- `distill-plugin/` — Claude Code plugin (`/distill`, `/codemap`). Manifest
  at `distill-plugin/.claude-plugin/plugin.json`. Root-level
  `.claude-plugin/marketplace.json` lists it so the repo can be added as a
  marketplace directly.

## Before finishing any change here

- If you touch `save-tokens/compress.js`, run
  `npm run sync-extension` from `save-tokens/` and `npm test` — a test
  fails the build if `extension/compress.js` drifts from the canonical copy.
- If you touch plugin manifests or command files under `distill-plugin/`,
  validate with `claude plugin validate distill-plugin --strict` before
  committing.
- Keep this file and per-directory `CODEMAP.md` files (generated by
  `distill-plugin/scripts/codemap.py`) up to date with structural changes.
